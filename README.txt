FAWWAZ.DEV — Personal Portfolio (Polished Version)

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder fawwaz-portfolio di VS Code.
3. Buka index.html di browser, atau gunakan ekstensi Live Server.
4. Ganti your.email@example.com di index.html dengan email aktif.
5. Tambahkan tautan GitHub/LinkedIn dan demo proyek ketika sudah tersedia.

Struktur:
- index.html
- style.css
- script.js
- assets/profile.jpg

Catatan:
- Foto profil yang kamu kirim sudah disertakan.
- Animasi dan efek visual dibuat ringan serta responsif.
- Property Sales Prediction ditandai sebagai konsep penelitian yang masih berjalan.
- Periksa kembali detail profil, pengalaman, dan skill sebelum website dipublikasikan.
